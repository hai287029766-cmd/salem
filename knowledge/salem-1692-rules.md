# Salem 1692 - 完整规则文档 (数字版实现参考)

> 设计师: Travis Hancock | 出版商: Facade Games (2015)
> 获奖: Dice Tower Seal of Excellence | 累计销量: 200,000+

---

## 1. 游戏概述

Salem 1692 是一款以1692年马萨诸塞州塞勒姆女巫审判为背景的社交推理卡牌游戏。玩家扮演塞勒姆小镇的居民,通过指控、辩护、阴谋和夜间行动来揭露隐藏在镇民中的女巫,或作为女巫消灭所有镇民。

- **玩家人数**: 4-12人 (豪华版支持2-3人变体)
- **游戏时长**: 20-40分钟
- **适龄**: 13+

## 2. 游戏组件 (128张卡牌 + 配件)

### 2.1 卡牌总览

游戏包含 **128张卡牌**, 分为以下大类:

| 类别 | 说明 |
|------|------|
| 审判卡 (Tryal Cards) | 身份卡, 面朝下放在玩家面前 |
| 城镇大厅卡 (Town Hall Cards) | 角色卡, 面朝上, 每人一张, 提供特殊能力 |
| 击杀卡 (Kill Cards) | 夜间阶段使用, 与城镇大厅卡一一对应 |
| 塞勒姆牌组 (Salem Deck) | 抽牌堆, 包含红/绿/蓝/黑四色卡牌 |

### 2.2 非卡牌组件

| 组件 | 说明 |
|------|------|
| 法槌令牌 (Gavel Token) | 木制法槌, 警长在夜间阶段放置以保护玩家 |
| 沙漏 (Hourglass) | 30秒黑沙沙漏, 用于限时决策(如认罪阶段) |
| 规则书 (Rulebook) | 含历史人物传记 |

## 3. 审判卡 (Tryal Cards) -- 身份系统

审判卡决定玩家的隐藏身份。游戏开始时面朝下分发给每位玩家。

### 3.1 审判卡类型

| 卡名(英) | 卡名(中) | 效果 |
|-----------|-----------|------|
| **Witch** | **女巫** | 拥有过此卡的玩家是女巫阵营。女巫在夜间选择击杀目标。 |
| **Not a Witch** | **非女巫** | 普通镇民, 无特殊效果。 |
| **Constable** | **警长** | 持有者在夜间阶段可放置法槌令牌保护一名玩家。可同时为女巫和警长。 |

### 3.2 审判卡分配表 (按玩家人数)

| 玩家人数 | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 11 | 12 |
|----------|---|---|---|---|---|---|----|----|-----|
| **非女巫 (Not a Witch)** | 18 | 23 | 27 | 32 | 29 | 33 | 27 | 30 | 33 |
| **女巫 (Witch)** | 1 | 1 | 2 | 2 | 2 | 2 | 2 | 2 | 2 |
| **警长 (Constable)** | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| **审判卡总数** | 20 | 25 | 30 | 35 | 32 | 36 | 30 | 33 | 36 |
| **每人卡数** | 5 | 5 | 5 | 5 | 4 | 4 | 3 | 3 | 3 |

**关键规则**:
- 4-5人游戏: 仅1名女巫
- 6-12人游戏: 2名女巫
- 警长始终为1名
- 一个玩家可能同时是女巫和警长(邪恶警长)

### 3.3 豪华版特殊审判卡 (Deluxe Edition Special Tryal Cards)

豪华版新增5张特殊审判卡。游戏开始时将5张洗混, 根据玩家人数取出指定数量加入审判卡堆(不看多余的), 因此每局不确定哪些特殊审判卡在场。

**特殊审判卡不代表阵营归属(既非女巫也非镇民), 但能在被翻开时给持有者带来优势。**

| 卡名(英) | 卡名(中) | 被翻开时效果 |
|-----------|-----------|-------------|
| **Charlatan** | **骗子** | 选择三名玩家(可包括自己), 对他们的审判卡进行某种洗牌/交换操作。剩余两名玩家时无效。 |
| **Gravedigger** | **掘墓人** | 将任意一名其他玩家的一张已翻开审判卡翻回面朝下(不能翻自己的)。该玩家必须立即洗混自己面朝下的审判卡。可以复活已被淘汰的玩家(前提是该玩家在被淘汰后没有在夜间阶段睁过眼)。女巫卡和特殊审判卡均可被复活。 |
| **Inquisitor** | **审判官** | 立即翻开任意其他玩家的一张审判卡。该玩家面前的指控卡不会因此被丢弃。 |
| **Magistrate** | **地方法官** | 拿取任意一个令牌(虔诚/庇护/黑猫/红线), 从任意玩家(包括自己)或中央处取走, 分配给任意其他玩家。 |
| **Pickpocket** | **扒手** | 偷取指控者(打出第7点指控的玩家)的全部手牌, 放入自己手中。 |

**特殊审判卡规则**:
- 特殊审判卡在被翻开时立即生效
- 认罪(Confess)时不能翻开特殊审判卡
- 如果玩家忘记在适用回合使用特殊能力, 则作废
- 被淘汰玩家仍应在夜间阶段闭眼(以防掘墓人复活他们); 获得新信息的已淘汰玩家不可被复活

## 4. 塞勒姆牌组 (Salem Deck) -- 抽牌堆卡牌

塞勒姆牌组是游戏的核心抽牌堆, 包含四种颜色的卡牌。

### 4.1 红色卡牌 (Red Cards) -- 指控卡

红色卡牌用于指控其他玩家。放置在目标玩家面前, 累计达到7点时触发审判。

| 卡名(英) | 卡名(中) | 指控值 | 效果 |
|-----------|-----------|--------|------|
| **Accusation** | **指控** | 1 | 值1点指控 |
| **Evidence** | **证据** | 3 | 值3点指控 |
| **Witness** | **证人** | 7 | 值7点指控(单张即可触发审判) |

**指控机制详解**:
- 红色卡牌放在目标玩家面前, 直到累计达到7点
- 达到7点时, 打出最后一张(第7点)指控卡的玩家选择目标玩家的一张面朝下审判卡翻开
- 翻开后, 该玩家面前的所有红色卡牌弃入弃牌堆
- 如果超过7点(例如对有6点指控的玩家打出一张3点证据卡), 多余的不累计到下次审判
- 如果目标玩家拥有虔诚(Piety)令牌/卡, 则需要14点指控才能触发审判

### 4.2 绿色卡牌 (Green Cards) -- 一次性行动卡

绿色卡牌使用后立即弃掉。

| 卡名(英) | 卡名(中) | 效果 |
|-----------|-----------|------|
| **Alibi** | **不在场证明** | 移除目标玩家面前的所有红色指控卡(全部弃掉) |
| **Stocks** | **枷锁** | 放在目标玩家面前, 该玩家跳过下一个回合。被跳过后弃掉。若被替罪羊移动, 枷锁跟着移动。两张枷锁=跳过两个回合。 |
| **Robbery** | **抢劫** | 从一名玩家处拿取卡牌交给另一名玩家。不能涉及自己(不能从别人处拿给自己, 也不能从自己处拿给别人)。必须涉及两名其他玩家。仅剩两名玩家时不可使用(视为蓝色卡牌处理)。 |
| **Scapegoat** | **替罪羊** | 将一名玩家面前的所有蓝色、绿色和红色卡牌转移给另一名玩家。不能涉及自己。枷锁也会被一起移动。仅剩两名玩家时不可使用(视为蓝色卡牌处理)。 |
| **Curse** | **诅咒** | 弃掉目标玩家面前的蓝色卡牌。黑猫也可被诅咒弃掉。 |

### 4.3 蓝色卡牌 (Blue Cards) -- 持续效果卡

蓝色卡牌放在目标玩家面前, 持续生效直到该玩家死亡, 或被其他卡牌(如替罪羊、诅咒)移除。

| 卡名(英) | 卡名(中) | 效果 |
|-----------|-----------|------|
| **Piety** | **虔诚** | 保护目标玩家不被直接打出指控卡。(豪华版中改为令牌: 需要双倍指控14点才能触发审判) |
| **Asylum** | **庇护** | 保护目标玩家不会在夜间被杀。 |
| **Matchmaker** | **红线(媒人)** | 游戏中有2张红线卡。分别放在两名不同玩家面前。若其中一名持有红线的玩家在夜间被杀, 另一名也同时死亡。若两张红线放在同一人面前, 则两张都弃掉。 |
| **Black Cat** | **黑猫** | 特殊蓝色卡。在黎明阶段由女巫放置。持有黑猫的玩家若抽到阴谋卡(Conspiracy), 可以自己选择翻开哪张审判卡。正常情况下是由左边玩家拿走一张。 |

### 4.4 黑色卡牌 (Black Cards) -- 立即生效事件卡

抽到黑色卡牌时必须立即展示给所有玩家, 效果立即生效。

| 卡名(英) | 卡名(中) | 数量 | 效果 |
|-----------|-----------|------|------|
| **Night** | **黑夜** | 1 | 触发夜间阶段。所有玩家闭眼, 女巫选择击杀目标, 警长选择保护对象。设置时放在牌堆最底部。(豪华版: 洗入牌堆下半部分) |
| **Conspiracy** | **阴谋** | 1 | 所有玩家将一张面朝下的审判卡传给左边的玩家。可能导致阵营变动! 若黑猫持有者抽到阴谋卡, 该持有者可选择翻开自己的哪张审判卡。设置时洗入牌堆。 |

游戏有15个可选角色, 均基于塞勒姆女巫审判中的真实历史人物。每位玩家获得一张城镇大厅卡(面朝上放置), 提供独特的特殊能力。

| **Thomas Danforth** | 托马斯-丹福斯 (法官) | 如果你打出第6点(而非第7点)指控, 你可以翻开该玩家的一张审判卡。 |

### 5.2 击杀卡 (Kill Cards)

- 击杀卡与城镇大厅卡一一对应, 每张城镇大厅卡有一张匹配的击杀卡
- 设置时, 选出游戏中所有玩家对应的击杀卡, 叠放在桌面中央
- 多余的击杀卡放回盒中
- 夜间阶段, 女巫选择一张击杀卡来指定目标
- 如果使用主持人(Moderator)模式, 击杀卡全部放回盒中(由主持人口头记录)

## 6. 游戏设置 (Setup)

### 6.1 指定报幕人 (Town Crier)

- 选择最有经验的玩家担任报幕人
- 报幕人负责在夜间阶段指挥所有人闭眼/睁眼
- **报幕人同时也是玩家**, 参与游戏
- 替代方案: 新手局或大型局可使用**主持人(Moderator)**代替报幕人, 主持人不参与游戏

### 6.2 分发角色

1. 洗混城镇大厅卡, 每人发1张, 面朝上放在面前
2. 向全组朗读自己角色的能力
3. 7人及以下: 可给每人发2张, 选1张保留, 另1张放回盒中

### 6.3 分发审判卡

1. 根据玩家人数取出对应数量的审判卡(参见3.2分配表)
2. 多余的审判卡放回盒中
3. 洗混审判卡, 平均分配给每位玩家(面朝下)
4. 每位玩家偷看自己的审判卡, 然后面朝下排成一排放在面前
5. 如果你拿到了"女巫(Witch)"卡 -- 你在本局余下时间都是女巫
6. 如果你拿到了"警长(Constable)"卡 -- 你在夜间阶段担任警长

### 6.4 准备塞勒姆牌组

1. 从牌组中取出: **黑猫(Black Cat)**、**黑夜(Night)**、**阴谋(Conspiracy)** 三张卡
2. 洗混剩余牌组
3. 给每位玩家发3张手牌
4. 将**阴谋(Conspiracy)**卡洗回牌组
5. 将**黑夜(Night)**卡放在牌堆**最底部**
6. 将**黑猫(Black Cat)**卡放在一旁备用

**豪华版设置差异**: 
- 取出黑夜卡后洗混发牌
- 若有玩家收到阴谋卡, 洗回牌组重新发牌
- 将牌堆切成两半, 将黑夜卡洗入**下半部分**, 然后合并两半

### 6.5 准备击杀卡

- 使用报幕人模式: 选出与游戏中玩家对应的击杀卡, 叠放在桌面中央
- 使用主持人模式: 全部击杀卡放回盒中

### 6.6 放置法槌

- 将法槌令牌(Gavel Token)放在桌面中央

## 7. 游戏流程

游戏分为: **黎明阶段 -> 白天回合(循环) -> 夜间阶段 -> 白天回合(循环) -> 夜间阶段...**

### 7.1 黎明阶段 (Dawn Phase) -- 仅游戏开局一次

黎明阶段是游戏的第一个阶段, 仅在游戏开始时执行一次。

**步骤**:
1. 报幕人将黑猫(Black Cat)卡面朝上、垂直放在牌堆顶部(方便女巫拿取)
2. 报幕人指示所有玩家闭眼
3. 报幕人指示拥有女巫卡的玩家睁眼
4. 女巫睁眼后, 将黑猫卡放在任意一名玩家面前(**例外: 女巫可以将黑猫放在自己面前, 这是"塞勒姆第一法则"的唯一例外**)
5. 报幕人从10开始倒数
6. 报幕人指示女巫闭眼
7. 报幕人指示所有玩家睁眼

**结果**: 被放置黑猫的玩家将黑猫面朝上放在自己审判卡前方。收到黑猫的玩家成为**第一个行动的玩家**, 游戏按顺时针进行。

### 7.2 白天回合 (Day Phase -- Player Turns)

从拥有黑猫的玩家开始, 顺时针轮流行动。

**每个玩家的回合二选一**:

#### 选项A: 出牌 (Play Cards)
- 打出**至少1张卡牌**(可以打出任意多张)
- 卡牌必须打在**其他玩家**身上(不能打在自己身上)
- 这是核心规则: **塞勒姆第一法则 (1st Law of Salem) -- 你永远不能对自己使用卡牌或法槌令牌**

#### 选项B: 抽牌 (Draw Cards)
- 从牌堆抽**2张卡牌**, 然后结束回合
- 如果抽到**黑色卡牌**(阴谋或黑夜), 必须立即展示并执行效果

### 7.3 塞勒姆第一法则 (1st Law of Salem)

**核心限制**: 你永远不能以直接影响自己的方式打出卡牌:
- 不能给自己打虔诚(Piety)
- 不能给自己打不在场证明(Alibi)
- 不能通过抢劫(Robbery)让别人给自己卡牌
- 不能通过替罪羊(Scapegoat)把卡牌移到自己面前
- 警长不能把法槌令牌放在自己面前

**唯一例外**: 女巫可以在黎明阶段将黑猫放在自己面前(用于误导)

### 7.4 指控与审判 (Accusation & Tryal)

1. 玩家将红色指控卡打在目标玩家面前
2. 红色卡牌累积在目标玩家面前, 直到总值达到7点
3. 达到7点时:
   - 打出最后一张(使其达到或超过7点)指控卡的玩家**选择**翻开目标玩家的一张面朝下审判卡
   - 目标玩家面前的所有红色卡牌弃入弃牌堆
   - 超出7点的部分**不累积**到下次审判
4. 如果翻开的是**女巫(Witch)**卡 -- 女巫身份暴露
5. 如果翻开的是**警长(Constable)**卡 -- 该玩家不一定死亡, 但警长角色从此不再使用(不在夜间行动)
6. 如果翻开的是**特殊审判卡**(豪华版) -- 立即触发该卡能力

### 7.5 玩家死亡条件

以下情况玩家死亡并被淘汰:
1. **所有审判卡被翻开** -- 无论内容如何, 全部面朝上则死亡
2. **夜间被女巫击杀** -- 除非被警长保护、拥有庇护卡、或选择认罪
3. **红线连带** -- 与被杀玩家通过红线(Matchmaker)绑定

**玩家死亡时**:
- 翻开所有剩余审判卡
- 将手牌和面前所有蓝色/绿色/红色卡牌弃入弃牌堆
- 如实告知是否曾拥有过女巫卡
- 退出游戏(豪华版中可能被掘墓人复活)

### 7.6 抽到黑色卡牌

#### 抽到阴谋 (Conspiracy)
1. 立即展示给所有玩家
2. **所有玩家**将自己的一张面朝下审判卡传给左边的玩家
3. 收到新审判卡的玩家偷看新卡, 然后面朝下放入自己的审判卡行列
4. **关键**: 这可能导致阵营变动! 一个原本无辜的人可能收到女巫卡而变成女巫
5. 特殊: 如果黑猫持有者抽到阴谋卡, 该持有者可以自己选择翻开哪张审判卡(而非由左边玩家指定)
6. 阴谋卡使用后弃入弃牌堆

#### 抽到黑夜 (Night)
- 立即进入夜间阶段(详见第8节)

## 8. 夜间阶段 (Night Phase)

当牌堆最后一张卡(黑夜卡)被翻出时, 进入夜间阶段。

### 8.1 夜间阶段流程(报幕人模式)

**步骤1: 关灯**
- 报幕人从20开始倒数
- 指示所有玩家闭眼(报幕人自己也应闭眼, 除非他/她是女巫)

**步骤2: 女巫行动**
- 报幕人指示女巫睁眼
- 女巫(们)睁眼后互相确认身份
- 女巫选择一张击杀卡, 对应他们要击杀的目标玩家
- 女巫也可以策略性地选择杀死自己的一名女巫同伴(伪装)
- 报幕人指示女巫闭眼

**步骤3: 警长行动**
- 报幕人指示警长睁眼
- 警长将法槌令牌放在任意一名**其他**玩家面前(不能放在自己面前)
- 如果警长同时也是女巫(邪恶警长), 可以故意保护错误的人来帮助女巫
- 报幕人从10开始倒数
- 报幕人指示警长闭眼

**步骤4: 所有人睁眼**
- 报幕人指示所有玩家睁眼

**步骤5: 认罪 (Confess)**
- 翻转沙漏(30秒)
- 在沙漏结束前, 任何玩家可以选择"认罪"
- **认罪**: 主动翻开自己的1张审判卡, 换取本次夜间免死
- 认罪不能翻开特殊审判卡(豪华版规则)
- 认罪是一种风险决策: 暴露信息但换取生存

**步骤6: 揭示击杀**
- 翻开女巫选择的击杀卡, 对应的玩家死亡
- **例外(免死)**:
  - 该玩家面前有**法槌令牌**(被警长保护)
  - 该玩家选择了**认罪**
  - 该玩家面前有**庇护(Asylum)**卡
- 如果目标未死: 收回击杀卡, 该玩家存活
- 如果目标死亡: 翻开所有剩余审判卡, 弃掉所有手牌和面前卡牌
- **红线连带**: 如果死亡玩家面前有红线卡, 另一名持有红线的玩家也同时死亡

### 8.2 夜间阶段后

- 收回法槌令牌放回桌面中央
- 收回所有击杀卡
- 重新洗混塞勒姆牌组(包括弃牌堆), 设置与开局相同:
  - 取出黑夜和阴谋卡
  - 洗混, 给每个存活玩家发3张手牌
  - 阴谋洗回牌堆
  - 黑夜放在牌堆底部
- 继续白天回合, 从上次行动玩家的下一位开始

## 9. 塞勒姆基本法则 (Laws of Salem) 汇总

| 法则 | 内容 |
|------|------|
| **第一法则** | 你永远不能对自己使用卡牌或法槌令牌 |
| **黑猫例外** | 女巫在黎明阶段可以将黑猫放在自己面前(唯一例外) |
| **警长限制** | 警长永远不能把法槌放在自己面前 |
| **抢劫/替罪羊限制** | 不能涉及自己; 必须在两名其他玩家之间操作 |
| **两人残局** | 仅剩两名玩家时, 所有蓝色卡牌从游戏中移除; 抽到蓝色卡牌时放在一旁重新抽; 替罪羊和抢劫不可使用 |

## 10. 胜利条件

### 10.1 镇民(Townspeople)胜利
- 揭露(翻开)游戏中**所有写着"Witch"的审判卡**
- 注意: 镇民是指**在整场游戏中从未拥有过女巫卡的玩家**(包括阴谋卡传递导致临时持有再传出的情况)

### 10.2 女巫(Witches)胜利
- 通过夜间击杀消灭**所有非女巫玩家**
- 注意: 女巫阵营包括**在游戏中任何时刻曾拥有过女巫审判卡的玩家**(即使后来通过阴谋卡把女巫卡传走了, 仍属于女巫阵营)

### 10.3 阵营判定的关键规则

- **一旦拥有过女巫卡, 永远是女巫阵营** -- 即使后来卡被传走
- **阴谋卡可以改变阵营** -- 原本清白的人收到女巫卡后变成女巫
- 这意味着女巫阵营的人数可能在游戏过程中**增加**(但不会减少)

## 11. 特殊规则与边缘情况

### 11.1 枷锁 (Stocks) 规则
- 放在玩家面前直到被跳过, 然后弃掉
- 替罪羊(Scapegoat)可以移动枷锁
- 两张枷锁 = 连续跳过两个回合

### 11.2 黑猫 (Black Cat) 完整规则
- 黎明阶段由女巫放置
- 黎明后视为普通蓝色卡牌
- 可被诅咒(Curse)弃掉
- 可被替罪羊(Scapegoat)移动
- 被弃掉后可以被正常抽取和使用(作为蓝色卡牌)
- 持有者抽到阴谋(Conspiracy)时可选择翻开自己的哪张审判卡

### 11.3 警长 (Constable) 完整规则
- 警长卡被翻开时, 该玩家不一定死亡
- 但警长角色从此退出游戏(夜间不再有人保护)
- 如果警长卡通过阴谋卡传给了另一个玩家, 新持有者成为新警长
- 如果你失去了警长卡, 你不再是警长, 夜间不应作为警长睁眼

### 11.4 两人残局规则
- 所有蓝色卡牌从游戏中弃掉
- 抽到蓝色卡牌时放在一旁, 重新抽一张
- 替罪羊和抢劫不可使用, 视为蓝色卡牌处理

### 11.5 认罪 (Confession) 详细规则
- 仅在夜间阶段所有人睁眼后、击杀揭示前可以认罪
- 认罪 = 主动翻开自己的1张审判卡(自选)
- 换取本次夜间击杀免疫
- 不能翻开特殊审判卡(豪华版)
- 认罪窗口由沙漏(30秒)限制
- 风险: 加速自己的审判卡被全部翻开(所有卡翻开 = 死亡)

### 11.6 豪华版令牌系统

豪华版中, 部分效果改为木质令牌(而非卡牌):

| 令牌(英) | 令牌(中) | 效果 |
|-----------|-----------|------|
| **Piety Token** | 虔诚令牌 | 持有者需要14点指控(双倍)才能触发审判 |
| **Asylum Token** | 庇护令牌 | 持有者免受夜间击杀 |
| **Matchmaker Tokens** (x2) | 红线令牌 | 两个令牌, 绑定两名玩家命运 |
| **Black Cat Token** | 黑猫令牌 | 与卡牌版效果相同 |

### 11.7 豪华版先令系统 (Shillings)

豪华版新增12枚金属先令:
- 先令卡和硬币允许玩家窥探特定的审判卡
- 具体规则需参照豪华版规则书

## 13. 数字版实现要点

### 13.1 核心游戏状态

```
GameState:
  phase: DAWN | DAY | NIGHT | GAME_OVER
  currentPlayerIndex: number
  turnDirection: CLOCKWISE
  players[]:
    id, name
    townHallCard: CharacterCard       // 面朝上的角色卡
    tryalCards[]: { type, faceUp }    // 审判卡列表
    handCards[]: Card[]               // 手牌
    frontCards[]: Card[]              // 面前放置的蓝/绿/红卡
    isAlive: boolean
    hasBeenWitch: boolean             // 是否曾拥有过女巫卡(决定胜利阵营)
    isConstable: boolean              // 当前是否持有警长卡
  deck[]: Card[]                      // 牌堆
  discardPile[]: Card[]               // 弃牌堆
  killCards[]: KillCard[]             // 击杀卡(对应存活玩家)
  gavelPosition: playerId | null      // 法槌位置
  blackCatOwner: playerId | null      // 黑猫持有者
```

### 13.2 回合逻辑

```
function playerTurn(player):
  if player has Stocks:
    remove Stocks, skip turn
    return

  choice = player.choose(PLAY_CARDS | DRAW_CARDS)

  if choice == PLAY_CARDS:
    while player wants to play more:
      card = player.selectFromHand()
      target = player.selectTarget()  // 不能选自己
      executeCard(card, target)

  if choice == DRAW_CARDS:
    for i in 1..2:
      card = deck.drawTop()
      if card.color == BLACK:
        revealAndExecute(card)
      else:
        player.hand.add(card)
```

### 13.3 指控计算

```
function checkAccusation(targetPlayer):
  totalPoints = sum(card.value for card in targetPlayer.frontCards where card.color == RED)
  threshold = 7
  if targetPlayer has Piety:
    threshold = 14
  if targetPlayer.townHall == "Thomas Danforth" and totalPoints >= 6:
    // Danforth的能力: 第6点就可以翻卡
    triggerTryal(targetPlayer, lastAccuser)
  if totalPoints >= threshold:
    triggerTryal(targetPlayer, lastAccuser)
```

### 13.4 夜间阶段逻辑

```
function nightPhase():
  // 所有人"闭眼"(数字版: 隐藏信息)
  
  // 女巫投票
  witchTarget = witches.vote(killCards)
  
  // 警长保护
  if constableAlive:
    gavelTarget = constable.choose(alivePlayers - constable)
  
  // 认罪窗口 (30秒)
  confessors = waitForConfessions(30_seconds)
  for player in confessors:
    player.revealOneTryalCard(choice)  // 玩家自选, 不能选特殊审判卡
  
  // 判定击杀
  targetPlayer = findPlayerByKillCard(witchTarget)
  if targetPlayer == gavelTarget:
    // 被警长保护, 存活
  elif targetPlayer in confessors:
    // 已认罪, 存活
  elif targetPlayer has Asylum:
    // 有庇护, 存活
  else:
    killPlayer(targetPlayer)
    // 检查红线连带
    if targetPlayer has Matchmaker:
      linkedPlayer = findMatchmakerPartner(targetPlayer)
      if linkedPlayer and linkedPlayer != targetPlayer:
        killPlayer(linkedPlayer)

  // 检查胜利条件
  checkWinConditions()
  
  // 重建牌堆
  rebuildDeck()
```

### 13.5 胜利条件检查

```
function checkWinConditions():
  // 检查镇民胜利: 所有女巫卡已翻开
  allWitchCardsRevealed = true
  for player in allPlayers:
    for card in player.tryalCards:
      if card.type == WITCH and not card.faceUp:
        allWitchCardsRevealed = false
  if allWitchCardsRevealed:
    return TOWNSPEOPLE_WIN

  // 检查女巫胜利: 所有非女巫玩家已死亡
  aliveNonWitches = players.filter(p => p.isAlive and not p.hasBeenWitch)
  if aliveNonWitches.length == 0:
    return WITCHES_WIN

  return CONTINUE
```

### 13.6 阴谋卡处理

```
function executeConspiracy():
  // 每人选一张面朝下的审判卡传给左边
  cardsToPass = {}
  for player in alivePlayers:
    card = player.chooseFaceDownTryalCard()
    leftNeighbor = getLeftNeighbor(player)
    cardsToPass[leftNeighbor] = card
  
  for player, card in cardsToPass:
    player.tryalCards.add(card)
    // 更新女巫状态
    if card.type == WITCH:
      player.hasBeenWitch = true
    // 更新警长状态
    if card.type == CONSTABLE:
      player.isConstable = true
```

### 13.7 数字版特殊考虑

1. **信息隔离**: 夜间阶段, 非女巫玩家不能看到女巫的选择; 非警长不能看到警长的选择
2. **计时器**: 认罪阶段需要30秒倒计时
3. **动画/揭示**: 审判卡翻开、击杀揭示需要戏剧性展示
4. **聊天系统**: 白天阶段应允许玩家自由讨论(文字/语音)
5. **阴谋卡UI**: 需要同时让所有玩家选择传递的卡牌, 然后同步揭示
6. **手牌隐藏**: 其他玩家不能看到你的手牌, 但面前的蓝/红卡公开可见
7. **回合提示**: 提示玩家只能选择"出牌"或"抽牌", 出牌至少1张
8. **角色能力**: 每个角色的能力需单独实现, 部分涉及特殊交互
