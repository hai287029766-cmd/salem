# Salem 1692 -- 执行计划 (Spec)

> 日期: 2026-05-15

## 任务分解

### Phase 1: 项目骨架 + 共享类型（串行，Tech Lead）
1. 初始化 monorepo（pnpm workspace）
2. 创建 shared 包：类型定义 + 卡牌常量 + 消息协议
3. 创建 server 包骨架（Colyseus）
4. 创建 client 包骨架（React + Vite + Tailwind）

### Phase 2: 核心开发（并行，前端 + 后端）

**后端 Agent（游戏引擎师 + 架构师）**:
1. Colyseus Schema 定义（SalemState / Player / Card）
2. SalemRoom 房间逻辑（创建/加入/断线重连）
3. GameEngine 核心状态机（全部阶段流转）
4. CardDeck 牌堆管理（洗牌/抽牌/弃牌/重建）
5. 指控系统 + 审判逻辑
6. 夜间阶段（女巫/警长/认罪）
7. 胜负判定
8. 阴谋卡处理
9. 协调员系统（暂停/延时/跳过）
10. 倒计时系统（含暂停支持）
11. LiveKit Token 生成接口
12. 角色能力系统（8个角色）

**前端 Agent（UI 工程师 + 交互设计师）**:
1. 路由 + 页面结构（Home/Lobby/Game/Result）
2. Colyseus 连接 Hook
3. 首页（创建/加入房间 + 昵称输入）
4. 等待室（玩家列表 + 准备 + 协调员指定）
5. 游戏主界面布局（玩家座位圆形排列）
6. 手牌组件（卡牌渲染 + 选择交互）
7. 操作面板（出牌/抽牌流程）
8. 夜间界面（女巫/警长/认罪）
9. 审判翻卡界面 + 动画
10. 协调员控制栏
11. 倒计时 + 暂停遮罩
12. 游戏日志
13. 阶段指示器
14. 结算页
15. LiveKit 语音组件
16. 音效系统

### Phase 3: 联调 + 部署（串行）
