## 1. 设计方向

### 1.1 视觉风格
- **主题**: 1692年塞勒姆女巫审判 -- 殖民时代暗色调
- **色调**: 深棕/暗金/羊皮纸色，搭配烛火暖光
- **质感**: 仿古纸张纹理、木质桌面、蜡封信件
- **字体**: 衬线体标题 + 无衬线正文
- **禁止**: 紫色渐变、emoji、现代极简风、AI 模板

### 1.2 设计 Token


**设计要点**:

**协调员控制栏设计要点**:
- 固定在顶部状态栏下方，金色边框区分
- 按钮使用暗金底色 + 图标（Lucide: Pause/Play/Clock/SkipForward）
- 暂停时按钮变为"继续"，绿色高亮
- 非协调员看不到控制栏
- 暂停时全屏半透明遮罩 + 暂停提示

**设计要点**:

**顶部状态栏**:
- 当前轮次 + 阶段（白天/夜间用不同颜色）
- 牌堆剩余数
- 操作倒计时（<10秒变红闪烁）

**玩家座位区**:
- 椭圆形排列，模拟围桌而坐
- 当前操作玩家：头像边框金色发光
- 已死亡玩家：灰化 + 骷髅标记
- 被指控中：头像下方显示红色指控条 (N/7)
- 有蓝色效果卡：小图标角标（庇护盾/红线心/虔诚十字/黑猫）
- 说话中：头像边框绿色波纹
- 本人座位：底部居中特殊高亮

**游戏日志**:
- 滚动文字，最新消息在底部
- 关键操作（审判/死亡/阶段切换）高亮显示

**手牌区**:
- 底部水平排列，可左右滑动
- 卡牌使用实物素材
- 点击选中 -> 弹起 -> 再点目标玩家出牌
- 卡牌颜色边框与类型对应（红/绿/蓝）

**操作区**:
- 两个大按钮：出牌 / 抽牌
- 非自己回合时灰化
- 麦克风控制常驻

## 3. 交互规范

### 3.1 卡牌操作流程

**出牌**:
1. 点击"出牌"按钮进入出牌模式
2. 从手牌中点选一张卡（卡牌弹起）
3. 点击目标玩家头像
4. 卡牌飞向目标玩家的动画
5. 效果立即生效并在日志中显示
6. 可继续出牌或点击"结束出牌"

**抽牌**:
1. 点击"抽牌"按钮
2. 牌堆飞出2张卡到手牌的动画
3. 若抽到黑色卡牌，自动全屏展示

### 3.2 倒计时处理

| 阶段 | 时限 | 超时行为 |
|------|------|----------|
| 白天回合 | 60秒 | 自动抽牌 |
| 夜间女巫 | 30秒 | 随机选目标 |
| 夜间警长 | 15秒 | 随机保护 |
| 认罪窗口 | 30秒 | 不认罪 |
| 审判翻卡 | 15秒 | 随机翻一张 |
| 阴谋传卡 | 30秒 | 随机传一张 |

### 3.3 触摸规范

- 所有可点击元素最小 44x44px
- 卡牌间距至少 8px，防误触
- 危险操作（认罪）需要二次确认
- 底部操作区在安全区域内（safe-area-inset-bottom）

## 4. 动画规范

| 动画 | 时长 | 效果 |
|------|------|------|
| 卡牌翻转 | 800ms | CSS 3D rotateY |
| 出牌飞行 | 400ms | 贝塞尔曲线位移 |
| 抽牌飞入 | 300ms | 从牌堆飞入手牌 |
| 阶段切换 | 1000ms | 全屏渐变过渡 |
| 玩家死亡 | 1200ms | 灰化 + 淡出 |
| 说话指示 | 循环 | 头像边框脉冲 |

## 6. 响应式设计

### 6.1 断点

| 设备 | 宽度 | 布局调整 |
|------|------|----------|
| 小屏手机 | 320-374px | 玩家头像缩小，手牌可滑动 |
| 标准手机 | 375-428px | 基准设计 |
| 大屏手机 | 429-480px | 更宽松的间距 |
| 平板(可选) | 768px+ | 横屏桌面视角 |

### 6.2 安全区域

```css
.bottom-action {
  padding-bottom: env(safe-area-inset-bottom, 16px);
}
```
