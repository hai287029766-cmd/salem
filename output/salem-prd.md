# Salem 1692 线上桌游 -- 产品需求文档 (PRD)

> 版本: 1.0 | 日期: 2026-05-15

---

## 1. 产品概述

### 1.1 产品定位
基于 Salem 1692 实体桌游的手机端 Web 在线版，支持 4-12 人实时语音对战。通过浏览器访问，无需下载安装。

### 1.2 目标用户
- Salem 1692 桌游爱好者
- 社交推理游戏玩家（狼人杀、谁是卧底等）
- 朋友聚会线上互动需求

### 1.3 核心价值
- 不受物理限制：异地也能语音面杀
- 无需实体卡牌：规则自动执行，减少记忆负担
- 快速开局：分享房间码即可加入

---

## 2. 功能需求

### 2.1 房间系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建房间 | 生成 6 位房间码，创建者为房主 | P0 |
| 加入房间 | 输入房间码 + 昵称加入 | P0 |
| 等待室 | 显示已加入玩家列表、准备状态 | P0 |
| 房主开始 | 满足最低人数(4人)后房主可开始 | P0 |
| 踢出玩家 | 房主可踢出等待中的玩家 | P1 |
| 断线重连 | 60秒内断线可自动重连恢复座位 | P0 |

### 2.2 语音系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 实时语音 | 进入房间后自动连接语音频道 | P0 |
| 麦克风控制 | 可静音/取消静音 | P0 |
| 夜间静音 | 夜间阶段自动全员静音（女巫除外） | P0 |
| 说话指示 | 显示谁正在说话 | P0 |
| 扬声器控制 | 可关闭对方声音 | P1 |

### 2.3 协调员系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 指定协调员 | 游戏开始前，房主可指定一名玩家为协调员（可以是房主自己） | P0 |
| 暂停/恢复游戏 | 协调员可随时暂停倒计时和游戏进程，暂停后全员看到暂停提示 | P0 |
| 跳过当前阶段 | 协调员可手动推进到下一阶段（如讨论够了直接进夜间） | P0 |
| 延长倒计时 | 协调员可为当前阶段追加时间（+30秒/+60秒） | P0 |
| 缩短倒计时 | 协调员可提前结束当前倒计时 | P0 |
| 强制静音/解除 | 协调员可控制单个玩家或全体的语音状态 | P1 |
| 协调员参与游戏 | 协调员同时也是玩家，正常参与游戏 | P0 |
| 协调员面板 | 协调员界面顶部有专属控制栏（暂停/继续/延时/跳过） | P0 |

**设计说明**: 协调员类似实体桌游中的"报幕人(Town Crier)"，参与游戏的同时负责管控节奏。系统自动推进是默认行为，协调员随时可以介入覆盖。

### 2.4 游戏核心流程

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 角色分配 | 随机发放城镇大厅卡 + 审判卡 | P0 |
| 黎明阶段 | 女巫放置黑猫，10秒倒计时 | P0 |
| 白天回合 | 出牌(至少1张)/抽牌(2张) 二选一 | P0 |
| 指控系统 | 红色卡牌累计7点触发翻卡审判 | P0 |
| 夜间阶段 | 女巫杀人 -> 警长保护 -> 认罪窗口(30秒) | P0 |
| 胜负判定 | 自动检测胜利条件并结算 | P0 |
| 阴谋卡 | 审判卡左传机制 | P0 |
| 角色能力 | 8个已确认角色的特殊能力 | P1 |
| 游戏日志 | 关键操作实时记录 | P0 |

### 2.4 卡牌与视觉

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 实物卡牌素材 | 使用 Salem 1692 实体卡牌图片 | P0 |
| 卡牌动画 | 翻牌、出牌、抽牌过渡效果 | P1 |
| 信息隔离 | 手牌和未翻审判卡对他人不可见 | P0 |

### 2.5 音效

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 翻牌音效 | 审判卡翻开 | P1 |
| 夜晚转换 | 进入/退出夜间的过渡音效 | P1 |
| 指控音效 | 打出指控卡 | P1 |
| 死亡音效 | 玩家被淘汰 | P1 |
| 静音开关 | 可关闭全部游戏音效 | P1 |

### 2.6 游戏进度系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 回合倒计时 | 白天操作 60秒，夜间操作 30秒，超时自动跳过/随机 | P0 |
| 倒计时暂停 | 协调员可暂停/恢复倒计时 | P0 |
| 系统自推进 | 所有人完成操作后自动切换下一阶段（协调员可覆盖） | P0 |
| 当前玩家高亮 | 明确显示轮到谁 | P0 |
| 阶段指示器 | 显示当前游戏阶段（黎明/白天/夜间） | P0 |
| 存活玩家计数 | 实时显示镇民/女巫存活状态（不泄露身份） | P0 |

## 3. 非功能需求

| 需求 | 指标 |
|------|------|
| 并发房间 | 50+ |
| 操作延迟 | < 200ms |
| 语音延迟 | < 300ms |
| 断线恢复 | 60秒窗口 |
| 浏览器兼容 | iOS Safari 15+ / Android Chrome 90+ |
| 屏幕适配 | 竖屏优先，375px-428px |

---

## 4. MVP 范围

### 包含
- 4-12 人基础游戏全流程
- 实时语音通话（LiveKit SFU）
- 房间创建/加入/断线重连
- 全部标准版卡牌（53张）
- 8 个已确认角色能力
- 实物卡牌素材
- 基础音效
- 自动游戏进度推进
- 回合倒计时

### 不包含
- 文字聊天（语音为主）
- 豪华版扩展（特殊审判卡、先令）
- 2-3人变体
- 账号系统/战绩记录
- 观战模式
- AI 玩家
