# Super Dev Codex Plugin

Repo-local Codex App/Desktop enhancement for Super Dev.

Primary entries:

- `/super-dev <需求>`
- `/super-dev-seeai <需求>`
- `$super-dev`
- `$super-dev-seeai`
- `super-dev: <需求>`
- `super-dev-seeai: <需求>`

The project-level official skill surface is also installed at `.agents/skills/`.
